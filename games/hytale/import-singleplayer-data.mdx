# Importing Singleplayer Progress to a Hytale Server

If you want to carry over your progress from singleplayer into your Hytale server, you can import your **player data**. This can bring over your character data, inventory, and progress so you don’t have to start over.

If you don’t have a server yet, start with [Hytale server hosting](https://berrybyte.net/hytale-server-hosting).

<Note>
Player data is tied to the universe it was created in. Make sure you upload the player data to the correct universe on your server.
</Note>

## Locate your singleplayer player data

1. Open Hytale
2. Click **Worlds**
3. Right-click any world that belongs to the universe you want to use
4. Click **Open Folder**
5. Open `universe/players/`

In this folder, you’ll see player data files (your character progress/inventory).

## Upload the data to your server

1. Stop your server
2. Open your server panel
3. Navigate to the **Files** tab
4. Open `universe/players/`
5. Upload your player data file(s) into this folder
6. Start your server

For best results, keep the server stopped while uploading player data.
