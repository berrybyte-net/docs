This guide shows you how to connect to a Hytale multiplayer server using share codes.

## Getting your share code

Your [Hytale dedicated server](https://berrybyte.net/hytale-server-hosting) will generate a share code you can use to invite friends.

1. Login to the [game control panel](https://game.berrybyte.net)
2. Locate the share code in your server details
3. Copy the code to share with your friends

## Joining with a share code

1. Launch Hytale
2. From the main menu, select **Servers**
3. Click **Join via Code**
4. Paste the share code from your friend or server
5. If a password is required, enter it
6. Click **Connect** to join!

Hytale will connect and load you into the multiplayer server.

For more details, check the [official Hytale joining guide](https://support.hytale.com/hc/en-us/articles/45324238811291-Joining-Friends).
