# How to Install Mods on a Hytale Server

Hytale server mods are **server-side only**, meaning players typically don’t need to install anything locally to join your modded Hytale server.

If you’re looking for an easy way to host a modded server, check out [Hytale server hosting](https://berrybyte.net/hytale-server-hosting).

## Download the mod you want

1. Find the mod you want on **CurseForge**
2. Download the mod file (commonly a `.zip` or `.jar`)

<Note>
Only install mods you trust. If a mod is outdated or incompatible, it may prevent your Hytale server from starting.
</Note>

## Upload the mod to your Hytale server

1. Open your server panel
2. Navigate to the **Files** tab
3. Open the `mods` folder
4. Upload the mod `.zip` or `.jar` file directly into the `mods` folder
5. Restart your Hytale server

## Confirm the mod is installed

After restart, check your server console/logs for any mod loading messages or errors. If the server fails to start, remove the last mod you added and restart again.
