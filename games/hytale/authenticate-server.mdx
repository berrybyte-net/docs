# How to Authenticate Your Hytale Server

Your [Hytale dedicated server](https://berrybye.net/hytale-server-hosting) needs to be authenticated once before it can start.

## With berrybyte

[berrybyte](https://berrybyte.net/hytale-server-hosting) automatically authenticates your server for you - **you don't need to do anything**. Your server will authenticate and start on its own.

## Manual authentication (if needed)

You'll only need to manually authenticate if:
- You've turned off **Automatic Authentication** in the Startup tab
- Automatic authentication fails for some reason

If you need to manually authenticate:

1. A **Hytale Authentication** modal will appear in your console
2. **Option 1:** Click **Authenticate Server** and it'll auto-authenticate if you're logged in
3. **Option 2:** Copy the **Device Code**, paste it on the authorization page, and click **Approve**

<Note>
Authentication is only required once per server. After the first time, your Hytale multiplayer server will start automatically.
</Note>

For more details, see the [official Hytale server manual](https://support.hytale.com/hc/en-us/articles/45326769420827-Hytale-Server-Manual).
